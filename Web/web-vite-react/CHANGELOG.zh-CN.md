## [6.6.2] - 2026-10-29

### Feat

- 直播列表页改用 Kit 提供的 `LiveList`，主播开播页改用 `LivePusher`。
- 观众端点击空麦位可直接申请上麦，申请时保留所选麦位。
- 按直播模板限制连麦方式：PC 连麦弹窗只展示当前模板支持的方式，H5 在模板不支持视频连麦时隐藏视频入口。

### 修复

- 空麦位点击不再被识别为点赞。
- 授权过程中模板发生变化时，按最新模板决定是否打开摄像头。
- H5 美颜滑块拖动不再卡顿，美颜参数正确映射到 SDK 取值范围。
- H5 开播倒计时结束后不再残留圆形底板；iOS H5 开播后前置画面不再放大。
- H5 主播开播前页增加返回按钮，更多设置中的镜像选项居中显示。
- H5 直播状态区分音视频关闭、异常与卡顿；直播数据与直播总结改为展示礼物收益与评论数，大数值紧凑显示。
- H5 主播连麦管理移除远端摄像头与麦克风开关。
- H5 连麦画面按麦位模板选择分屏布局；PC 与 H5 的连麦布局名称和排列顺序保持一致。
- PC 主播直播中打开弹窗不再遮挡画面。
- 移除 H5 弹幕中的观众等级 Mock 与观众关注按钮。
- H5 主播端直播画面在舞台内垂直居中，主播画面底部与连麦小窗不再被截断。
